These are glitches involving the move [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)").

## Generation I

*Main article: [List of glitches in Generation I](https://bulbapedia.bulbagarden.net/wiki/List_of_glitches_in_Generation_I "List of glitches in Generation I")*

### \--

*Main article: [\-- (move)](https://bulbapedia.bulbagarden.net/wiki/--_\(move\) "-- (move)")*

In Generation I, if a Pokémon transforms into another Pokémon that knows more moves and, while transformed, switches around the copied moves with the **SELECT** button, after the battle the Pokémon will not have [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)") and will instead have the [glitch move](https://bulbapedia.bulbagarden.net/wiki/Glitch_move "Glitch move") [\--](https://bulbapedia.bulbagarden.net/wiki/--_\(move\) "-- (move)"). This can also be done with Pokémon that have used [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)") in order to use Transform.

### Ditto glitch

*Main article: [Mew glitch](https://bulbapedia.bulbagarden.net/wiki/Mew_glitch#Ditto_glitch "Mew glitch")*

The primary method of the Mew glitch involves having a wild Ditto transform into the player's Pokémon, as this copies the [Special](https://bulbapedia.bulbagarden.net/wiki/Stat#Special "Stat") stat, which is used to modify the species of Pokémon encountered.

### Color loss glitch

In [Pokémon Red and Blue](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Red_and_Blue_Versions "Pokémon Red and Blue Versions") (when the games are played in [color](https://bulbapedia.bulbagarden.net/wiki/Color_palette_\(Generations_I%E2%80%93II\) "Color palette (Generations I–II)")), a transformed Pokémon initially keeps its own color palette when transformed, but it changes into the Ditto color palette once its sprite is reloaded.

Some examples:

- [Mew](https://bulbapedia.bulbagarden.net/wiki/Mew_\(Pok%C3%A9mon\) "Mew (Pokémon)") is the only Pokémon other than Ditto that is able to learn Transform in this generation. If a Mew uses Transform on [Pikachu](https://bulbapedia.bulbagarden.net/wiki/Pikachu_\(Pok%C3%A9mon\) "Pikachu (Pokémon)"), then Mew will initially transform into a Pikachu with Mew's color palette. However, it will change to Ditto's color palette once the sprite is reloaded. (Note: Mew and Ditto's color palettes are similar in [Pokémon Red and Blue](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Red_and_Blue_Versions "Pokémon Red and Blue Versions"), although their palettes are more distinct in [Pokémon Yellow](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Yellow_Version "Pokémon Yellow Version").)
- If a [Squirtle](https://bulbapedia.bulbagarden.net/wiki/Squirtle_\(Pok%C3%A9mon\) "Squirtle (Pokémon)") uses Transform (possibly via [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)")) on Pikachu, then Squirtle will initially transform into a blue Pikachu (using Squirtle's color palette). Once again, when its sprite is reloaded, it will use Ditto's color palette instead.

These are examples of actions that reload the Pokémon sprite in battle:

- If the transformed Pokémon uses Transform again.
- If the other Pokémon successfully uses any move on the transformed Pokémon.
- If the opposing Pokémon is transformed and the player throws a [Poké Ball](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9_Ball "Poké Ball") on it (including a failed Poké Ball thrown in a battle against a [Trainer](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Trainer "Pokémon Trainer")).
- If the player opens the [party](https://bulbapedia.bulbagarden.net/wiki/Party "Party") screen and returns to battle.

For comparison, this does not happen in [Pokémon Yellow](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Yellow_Version "Pokémon Yellow Version") and [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II"), because then the transformed Pokémon keeps its own color palette indefinitely. For instance, if a Squirtle uses Transform (again via Mimic) on Pikachu, it becomes a blue Pikachu indefinitely in Generation II.

### Level up moveset glitch

Only in [Generation I](https://bulbapedia.bulbagarden.net/wiki/Generation_I "Generation I"), if a transformed Pokémon levels up and learns a new move, it will use its original moveset (unaffected by Transform) from this point onwards in the current battle. Additionally, any PP lost from this point onwards in the current battle will not affect the Pokémon's actual PP as shown in the [summary](https://bulbapedia.bulbagarden.net/wiki/Summary "Summary"), which will effectively be restored once the transformed Pokémon switches out, faints, or the battle ends.

For instance, if a [Mew](https://bulbapedia.bulbagarden.net/wiki/Mew_\(Pok%C3%A9mon\) "Mew (Pokémon)") transformed into [Pikachu](https://bulbapedia.bulbagarden.net/wiki/Pikachu_\(Pok%C3%A9mon\) "Pikachu (Pokémon)") reaches the level 20 and learns [Mega Punch](https://bulbapedia.bulbagarden.net/wiki/Mega_Punch_\(move\) "Mega Punch (move)"), then it will have Mew's moveset (including Mega Punch) from this point onwards in the current battle, not Pikachu's moveset (even though Mew remains transformed into Pikachu). If that Mew had 29 PP remaining for [Pound](https://bulbapedia.bulbagarden.net/wiki/Pound_\(move\) "Pound (move)") when it transformed, then it will still lose PP as usual for each use of Pound, if any (decreasing to 28 PP, then 27 PP, and so on), but once the current battle ends, Mew will still have 29 PP for Pound, just like it had before transforming.

### Unused catch rate

In this generation only, Transform copies an unused [catch rate](https://bulbapedia.bulbagarden.net/wiki/Catch_rate "Catch rate") value from the target Pokémon. However, this has no effect in gameplay. If the player attempts to catch a transformed wild Pokémon, the catch rate from its original species is used, instead of the catch rate value that was copied by Transform.

## Generations I and II

### Transform assumption oversight

Only in Generations [I](https://bulbapedia.bulbagarden.net/wiki/Generation_I "Generation I") and [II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II"), if the player catches any transformed Pokémon, that Pokémon is permanently converted to a [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)"). All the moves previously known by this Pokémon are lost, as its only move when caught will be [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)"). This unlocks the [Pokédex entry](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9dex_entry "Pokédex entry") of Ditto instead of the original species.

[Mew](https://bulbapedia.bulbagarden.net/wiki/Mew_\(Pok%C3%A9mon\) "Mew (Pokémon)") and some [glitch Pokémon](https://bulbapedia.bulbagarden.net/wiki/Glitch_Pok%C3%A9mon "Glitch Pokémon") can potentially have Transform in their moveset, and several other Pokémon can also use Transform via [Mirror Move](https://bulbapedia.bulbagarden.net/wiki/Mirror_Move_\(move\) "Mirror Move (move)"), [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)"), or [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)"). Therefore, if the player catches any of these Pokémon that has used Transform, instead they will obtain a Ditto. However, wild Mew turning into Ditto is not an issue in normal gameplay, because wild Mew cannot be legitimately encountered prior to [Generation III](https://bulbapedia.bulbagarden.net/wiki/Generation_III "Generation III") in the first place. Conversely, the [Clefairy](https://bulbapedia.bulbagarden.net/wiki/Clefairy_\(Pok%C3%A9mon\) "Clefairy (Pokémon)"), [Pidgey](https://bulbapedia.bulbagarden.net/wiki/Pidgey_\(Pok%C3%A9mon\) "Pidgey (Pokémon)"), and [Spearow](https://bulbapedia.bulbagarden.net/wiki/Spearow_\(Pok%C3%A9mon\) "Spearow (Pokémon)") lines, which can be found in the wild, are able to use Transform via Metronome and Mirror Move, and then turn into Ditto on capture.

In Generation I games, the caught Ditto has Ditto's [catch rate](https://bulbapedia.bulbagarden.net/wiki/Catch_rate "Catch rate") in the game data. Therefore, it will be holding a [Metal Powder](https://bulbapedia.bulbagarden.net/wiki/Metal_Powder "Metal Powder") if [transferred](https://bulbapedia.bulbagarden.net/wiki/Transfer "Transfer") to a Generation II game (regardless of the original species).

In Generation II games, the [held item](https://bulbapedia.bulbagarden.net/wiki/Held_item "Held item") (if any) is unaffected by this glitch. If the wild Pokémon was holding any item before using Transform, the caught Ditto will still be holding that item.

### Transform DV manipulation glitch

If the opposing Pokémon (either a [wild Pokémon](https://bulbapedia.bulbagarden.net/wiki/Wild_Pok%C3%A9mon "Wild Pokémon") or a Pokémon owned by a [non-player character](https://bulbapedia.bulbagarden.net/wiki/Non-player_character "Non-player character")) uses [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)") twice in the same battle (that is, uses Transform when it is already transformed), it will retain the [DVs](https://bulbapedia.bulbagarden.net/wiki/Individual_values "Individual values") of the penultimate Pokémon it transformed into.

There are some additional effects:

- If a wild Pokémon uses Transform twice, and then is [caught](https://bulbapedia.bulbagarden.net/wiki/Caught_Pok%C3%A9mon "Caught Pokémon") by the player, these manipulated DVs are kept by the caught Pokémon. However, the caught Pokémon will always be [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)") due to the [Transform assumption glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_assumption_glitch).
- In [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II") only, if a Pokémon owned by a [non-player character](https://bulbapedia.bulbagarden.net/wiki/Non-player_character "Non-player character") uses Transform twice, and then the player uses [Roar](https://bulbapedia.bulbagarden.net/wiki/Roar_\(move\) "Roar (move)") or [Whirlwind](https://bulbapedia.bulbagarden.net/wiki/Whirlwind_\(move\) "Whirlwind (move)") to force the NPC to switch Pokémon, the next Pokémon sent as a result of this move will have the same manipulated DVs as the previous Pokémon. (conversely, if the NPC switches Pokémon because the previous Pokémon fainted, the next Pokémon sent will have its original DVs, unaffected by this glitch)
	- See [Roar/Whirlwind shared DV glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Roar/Whirlwind_shared_DV_glitch).

Some examples:

- If the player already has any Pokémon with Transform ([Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)"), [Mew](https://bulbapedia.bulbagarden.net/wiki/Mew_\(Pok%C3%A9mon\) "Mew (Pokémon)") or certain [glitch Pokémon](https://bulbapedia.bulbagarden.net/wiki/Glitch_Pok%C3%A9mon "Glitch Pokémon")) that has perfect DVs (15 for Attack, Defense, Speed, and Special), then this glitch can be used to catch wild Ditto perfect DVs as well. This is accomplished by waiting for a wild Ditto to use Transform twice against the player's Pokémon, and then [catching](https://bulbapedia.bulbagarden.net/wiki/Caught_Pok%C3%A9mon "Caught Pokémon") this wild Ditto.
	- In [Generation I](https://bulbapedia.bulbagarden.net/wiki/Generation_I "Generation I") only, if the player has any Pokémon with [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)"), then it is also possible to catch a wild Ditto with the same DVs as the player's Pokémon. This is accomplished if the player's Pokémon uses Mimic and copies Ditto's Transform, and then the wild Ditto uses Transform twice (by first using its original Transform move, and then using Transform that was copied by the player with Mimic).
		- In both Generations [I](https://bulbapedia.bulbagarden.net/wiki/Generation_I "Generation I") and [II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II"), the move [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)") has a slim chance of calling Transform as well. This can be used to perform this glitch.
- This glitch can be used to catch a Shiny [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)").
	- See [Shiny Ditto glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Shiny_Ditto_glitch).
- This glitch can be used to change the gender of the opposing Pokémon.
	- See [Transform gender change glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_gender_change_glitch).

### Shiny Ditto glitch

In Generations I and II, if a non-Shiny wild Ditto uses Transform on a Shiny Pokémon owned by the player, and then uses Transform again in the same battle, this Ditto will become permanently [Shiny](https://bulbapedia.bulbagarden.net/wiki/Shiny_Pok%C3%A9mon "Shiny Pokémon"). This is based on the [Transform DV manipulation glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_DV_manipulation_glitch).

Examples:

- If the player has any [Shiny Pokémon](https://bulbapedia.bulbagarden.net/wiki/Shiny_Pok%C3%A9mon "Shiny Pokémon") with [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)") (possibly a Shiny [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)"), [Mew](https://bulbapedia.bulbagarden.net/wiki/Mew_\(Pok%C3%A9mon\) "Mew (Pokémon)"), [Smeargle](https://bulbapedia.bulbagarden.net/wiki/Smeargle_\(Pok%C3%A9mon\) "Smeargle (Pokémon)"), or [glitch Pokémon](https://bulbapedia.bulbagarden.net/wiki/Glitch_Pok%C3%A9mon "Glitch Pokémon")), they can use it in battle against a non-Shiny wild Ditto. The wild Ditto will use its original Transform first, and then use the Transform copied from the player's Shiny Pokémon, permanently becoming Shiny.
- If the player has any Shiny Pokémon with [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)") (possibly Shiny [Cleffa](https://bulbapedia.bulbagarden.net/wiki/Cleffa_\(Pok%C3%A9mon\) "Cleffa (Pokémon)") from the [Odd Egg](https://bulbapedia.bulbagarden.net/wiki/Odd_Egg "Odd Egg") after it evolves into [Clefairy](https://bulbapedia.bulbagarden.net/wiki/Clefairy_\(Pok%C3%A9mon\) "Clefairy (Pokémon)") and learns Metronome at level 34; or alternatively, a Shiny [Togepi](https://bulbapedia.bulbagarden.net/wiki/Togepi_\(Pok%C3%A9mon\) "Togepi (Pokémon)"), [Togetic](https://bulbapedia.bulbagarden.net/wiki/Togetic_\(Pok%C3%A9mon\) "Togetic (Pokémon)"), [Mew](https://bulbapedia.bulbagarden.net/wiki/Mew_\(Pok%C3%A9mon\) "Mew (Pokémon)"), or [glitch Pokémon](https://bulbapedia.bulbagarden.net/wiki/Glitch_Pok%C3%A9mon "Glitch Pokémon")), they can use it in battle against a non-Shiny wild Ditto. The wild Ditto will use its original Transform first, copying the player's Shiny Pokémon with Metronome. For the remainder of the battle, Ditto will keep using Metronome as long as it has any [PP](https://bulbapedia.bulbagarden.net/wiki/PP "PP") left. If the transformed Ditto's Metronome calls Transform, Ditto will permanently become Shiny.
	- This method is likely to be faster in Generation I because there are fewer possible moves to be called by Metronome than in Generation II.
		- If this method is performed in Generation I, the transformed wild Ditto will be able to use Metronome as many times as needed until it hits Transform due to the fact that wild Pokémon have infinite [PP](https://bulbapedia.bulbagarden.net/wiki/PP "PP"). In Generation II, the transformed wild Ditto will have 5 attempts to use Metronome until it runs out of PP, at which point the player can try again by battling another wild Ditto.
- In Generation I, if the player has any Shiny Pokémon with [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)") (possibly learned from [TM31](https://bulbapedia.bulbagarden.net/wiki/TM31 "TM31")), they can use it in battle against a non-Shiny wild Ditto. This is the only generation where Mimic can copy a move that the target has not used yet. Therefore, the player's Pokémon can use Mimic and copy Ditto's Transform. Once Ditto transforms into the player's Shiny Pokémon, it will copy Transform back. After the wild Ditto uses Transform twice, it will permanently become Shiny.

In Generation I, this method works normally but the caught Shiny Ditto will only appear as Shiny when [traded](https://bulbapedia.bulbagarden.net/wiki/Trade "Trade") to [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II"), used in [Pokémon Stadium 2](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Stadium_2 "Pokémon Stadium 2") with [Transfer Pak](https://bulbapedia.bulbagarden.net/wiki/Transfer_Pak "Transfer Pak"), or [transfered](https://bulbapedia.bulbagarden.net/wiki/Transfer "Transfer") from the [Nintendo 3DS](https://bulbapedia.bulbagarden.net/wiki/Nintendo_3DS "Nintendo 3DS") [Virtual Console](https://bulbapedia.bulbagarden.net/wiki/Virtual_Console "Virtual Console") into [Pokémon Bank](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Bank "Pokémon Bank").

In Generation II, the non-Shiny Ditto converted into Shiny Ditto will still appear with its original color palette at first until the player reloads its sprite, such as by entering and exiting the [party](https://bulbapedia.bulbagarden.net/wiki/Party "Party") or [Pack](https://bulbapedia.bulbagarden.net/wiki/Bag "Bag") screens during battle.

Conversely, this glitch can also be used to turn a Shiny Ditto into non-Shiny. If a wild Shiny Ditto uses Transform on the player's non-Shiny Pokémon and then uses Transform again, it will be permanently converted into a non-Shiny Ditto. If this glitch is performed multiple times in the same battle using the player's Shiny and non-Shiny Pokémon with Transform, a wild Ditto can freely switch between the Shiny and non-Shiny versions.

This method cannot be used to catch the Shiny version of any other [Pokémon species](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_\(species\) "Pokémon (species)"). For instance, if a non-Shiny wild [Smeargle](https://bulbapedia.bulbagarden.net/wiki/Smeargle_\(Pok%C3%A9mon\) "Smeargle (Pokémon)") uses Transform on the player's Shiny Pokémon and then uses Transform again in the same battle, this glitch still works but the caught Pokémon will be a Shiny Ditto, not a Shiny Smeargle.

The player's Pokémon are unaffected by this glitch, as they are unable to become Shiny by using Transform twice in the same battle.

The [non-player character](https://bulbapedia.bulbagarden.net/wiki/Non-player_character "Non-player character") 's Pokémon are affected by [a related glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Roar/Whirlwind_shared_DV_glitch) due to using the same DVs after switching Pokémon.

### Transform gender change glitch

This is based on the [Transform DV manipulation glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_DV_manipulation_glitch).

This glitch can be used to change the gender of a male or female Pokémon in battle. It works with [wild Pokémon](https://bulbapedia.bulbagarden.net/wiki/Wild_Pok%C3%A9mon "Wild Pokémon"), as well as Pokémon owned by a [non-player character](https://bulbapedia.bulbagarden.net/wiki/Non-player_character "Non-player character"). However, if a wild Pokémon is caught after this glitch is performed, it will become a [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)") (a Pokémon species that is [gender unknown](https://bulbapedia.bulbagarden.net/wiki/Gender_unknown "Gender unknown")) because of the [Transform assumption glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_assumption_glitch).

Usually, a Pokémon that uses Transform keeps its original gender, even while it is transformed. For instance, a female [Smeargle](https://bulbapedia.bulbagarden.net/wiki/Smeargle_\(Pok%C3%A9mon\) "Smeargle (Pokémon)") using Transform stays female during its transformation, no matter the gender of the copied Pokémon. However, due to [gender](https://bulbapedia.bulbagarden.net/wiki/Gender "Gender") being determined by DVs in Generation II, if a male or female Pokémon transforms into a Pokémon with the correct DVs for the opposite gender (according to the gender ratio of the original species before it was transformed), and then uses Transform again, then the gender of the transformed Pokémon will change.

For instance, [Clefairy](https://bulbapedia.bulbagarden.net/wiki/Clefairy_\(Pok%C3%A9mon\) "Clefairy (Pokémon)") 's gender ratio is [one male to three females](https://bulbapedia.bulbagarden.net/wiki/Category:Pok%C3%A9mon_with_a_gender_ratio_of_one_male_to_three_females "Category:Pokémon with a gender ratio of one male to three females"), therefore any Clefairy with an [Attack](https://bulbapedia.bulbagarden.net/wiki/Stat#Attack "Stat") DV between 0-11 is female, and between 12-15 is male. If the player uses a Ditto with 15 Attack DVs against a female Clefairy, and then Clefairy uses [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)") to call [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)"), Clefairy will become a Ditto as well. At this point, Clefairy will have Ditto's DVs, but will retain its female gender symbol because Clefairy's original DVs are still used to determine its gender. If the player then switches to [Pikachu](https://bulbapedia.bulbagarden.net/wiki/Pikachu_\(Pok%C3%A9mon\) "Pikachu (Pokémon)"), and Clefairy (transformed into Ditto) uses Transform again, Clefairy will transform into a Pikachu and will become male (its gender symbol will change to male), because Ditto's DVs are now used to determine Clefairy's gender.

Additionally, if the player performs this glitch against a non-player character's Pokémon, and then the player uses [Roar](https://bulbapedia.bulbagarden.net/wiki/Roar_\(move\) "Roar (move)") or [Whirlwind](https://bulbapedia.bulbagarden.net/wiki/Whirlwind_\(move\) "Whirlwind (move)") to force the NPC to switch Pokémon, then the [Roar/Whirlwind shared DV glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Roar/Whirlwind_shared_DV_glitch) will be activated as well. This means that the next Pokémon sent by the NPC will have the same DVs and therefore will also change its gender, depending on their [gender ratio](https://bulbapedia.bulbagarden.net/wiki/Gender_ratio "Gender ratio").

## Generation II

### Roar/Whirlwind shared DV glitch

This is based on the [Transform DV manipulation glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_DV_manipulation_glitch).

In [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II") only, if a Pokémon owned by a [non-player character](https://bulbapedia.bulbagarden.net/wiki/Non-player_character "Non-player character") uses Transform twice, and then the player uses [Roar](https://bulbapedia.bulbagarden.net/wiki/Roar_\(move\) "Roar (move)") or [Whirlwind](https://bulbapedia.bulbagarden.net/wiki/Whirlwind_\(move\) "Whirlwind (move)") to force the NPC to switch Pokémon, the next Pokémon sent as a result of this move will have the same manipulated DVs as the previous Pokémon. (conversely, if the NPC switches Pokémon because the previous Pokémon fainted, the next Pokémon sent will have its original DVs, unaffected by this glitch)

For instance, if the player uses a Ditto with the lowest possible DVs (0 for Attack, Defense, Speed, and Special), and the NPC's Pokémon uses Transform twice against this Ditto (the first Transform possibly from [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)"), and the second Transform copied from Ditto), then the NPC's Pokémon will retain these DVs as well. If the player uses Roar or Whirlwind to force the NPC to switch Pokémon, then the next Pokémon will have 0 DVs as well.

Additionally, this glitch can be used to transform the NPC's Pokémon into [Shiny Pokémon](https://bulbapedia.bulbagarden.net/wiki/Shiny_Pok%C3%A9mon "Shiny Pokémon"), and/or to change their [gender](https://bulbapedia.bulbagarden.net/wiki/Gender "Gender") (see [Transform gender change glitch](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_gender_change_glitch)) by manipulating their DVs.

If the NPC copies the DVs of a [Shiny Pokémon](https://bulbapedia.bulbagarden.net/wiki/Shiny_Pok%C3%A9mon "Shiny Pokémon") owned by the player by using this glitch, the next Pokémon sent by the NPC as a result of Roar or Whirlwind will be Shiny as well. That Shiny Pokémon will display the sparkle animation when entering battle, but it will appear with the non-Shiny color palette at first. Once the player opens the [party](https://bulbapedia.bulbagarden.net/wiki/Party "Party") or [Pack](https://bulbapedia.bulbagarden.net/wiki/Bag "Bag"), that NPC's Pokémon will appear with the Shiny color palette.

As another example, this glitch may be performed to cause [Whitney](https://bulbapedia.bulbagarden.net/wiki/Whitney "Whitney") 's [Clefairy](https://bulbapedia.bulbagarden.net/wiki/Clefairy_\(Pok%C3%A9mon\) "Clefairy (Pokémon)") and [Miltank](https://bulbapedia.bulbagarden.net/wiki/Miltank_\(Pok%C3%A9mon\) "Miltank (Pokémon)") to be [Shiny](https://bulbapedia.bulbagarden.net/wiki/Shiny_Pok%C3%A9mon "Shiny Pokémon"). One possible way to do this would be by battling her with a Shiny [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)") as the first Pokémon, and a [Pidgeot](https://bulbapedia.bulbagarden.net/wiki/Pidgeot_\(Pok%C3%A9mon\) "Pidgeot (Pokémon)") with [Whirlwind](https://bulbapedia.bulbagarden.net/wiki/Whirlwind_\(move\) "Whirlwind (move)") to be used later. The player's Ditto must not use Transform (that is, it must stay as a Ditto). If Whitney's [Clefairy](https://bulbapedia.bulbagarden.net/wiki/Clefairy_\(Pok%C3%A9mon\) "Clefairy (Pokémon)") uses [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)") and calls Transform, then Clefairy will transform into Ditto. Once Clefairy is transformed, the player may switch into Pidgeot. After Whitney's Clefairy (transformed into Ditto) uses Transform for the second time, it will transform into Pidgeot and will retain the Shiny Ditto's DVs (even though Clefairy will not appear as Shiny yet). If Pidgeot uses Whirlwind, it will force Whitney to switch into Miltank, which will have the same DVs and therefore will be Shiny. If Pidgeot uses Whirlwind again, Whitney's Clefairy will be switched back, and will be Shiny as well.

### Sketch glitch

In [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II"), if a Pokémon uses [Sketch](https://bulbapedia.bulbagarden.net/wiki/Sketch_\(move\) "Sketch (move)") while transformed, it will permanently learn the sketched move, normally replacing Transform. A move can then be passed down as an [Egg Move](https://bulbapedia.bulbagarden.net/wiki/Egg_Move "Egg Move") through [breeding](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_breeding "Pokémon breeding") with a female Pokémon if the transforming Pokémon is [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)") or male.

In this generation, Sketch was intended to fail if the *user* is transformed, which is what it does in later generations, and would prevent this glitch from happening, but due to an oversight, it fails if the *target* is transformed.[^1] [^2]

This was commonly exploited with Ditto by using a [Trainer House](https://bulbapedia.bulbagarden.net/wiki/Trainer_House "Trainer House") Trainer who has a [Smeargle](https://bulbapedia.bulbagarden.net/wiki/Smeargle_\(Pok%C3%A9mon\) "Smeargle (Pokémon)") acquired using [Mystery Gift](https://bulbapedia.bulbagarden.net/wiki/Mystery_Gift "Mystery Gift"). The most popular method was to face this Trainer in the Trainer House and have the user's Pokémon Transform into a Smeargle with at least one move other than Sketch. The user's Pokémon could then copy the other move via Sketch or if necessary defeat the Smeargle and Sketch another attack.

Alternatively, a Pokémon with [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)") has a slim chance of using Transform, giving it the chance to copy a move via Sketch which replaces Metronome with this move at the end of the battle. This includes several Pokémon who learn Metronome from [TM35](https://bulbapedia.bulbagarden.net/wiki/TM35 "TM35") in [Generation I](https://bulbapedia.bulbagarden.net/wiki/Generation_I "Generation I") ([Mewtwo](https://bulbapedia.bulbagarden.net/wiki/Mewtwo_\(Pok%C3%A9mon\) "Mewtwo (Pokémon)"), [Gengar](https://bulbapedia.bulbagarden.net/wiki/Gengar_\(Pok%C3%A9mon\) "Gengar (Pokémon)"), [Golem](https://bulbapedia.bulbagarden.net/wiki/Golem_\(Pok%C3%A9mon\) "Golem (Pokémon)"), etc.) who can be [traded](https://bulbapedia.bulbagarden.net/wiki/Trade "Trade") to a [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II") game and permanently learn new moves by using this glitch.

Additionally, glitches with the potential of changing the species of another Pokémon such as the [Pokémon merge glitch](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_merge_glitch "Pokémon merge glitch") can also be used as part of extensions of the Sketch glitch in order to teach Pokémon Transform or Metronome to exploit the Sketch glitch.

In Gold and Silver, this glitch can be used to obtain Pokémon with [Egg Moves](https://bulbapedia.bulbagarden.net/wiki/Egg_Move "Egg Move") that are otherwise unobtainable:

### Wild Ditto's Transform with full PP

In [Generation II](https://bulbapedia.bulbagarden.net/wiki/Generation_II "Generation II"), if a transformed [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)") (or another Pokémon that uses Transform and is [permanently converted into a Ditto](https://bulbapedia.bulbagarden.net/wiki/List_of_Transform_glitches#Transform_assumption_glitch)) is caught by the player, it will have Transform with full PP (10 out of 10).

In Generation II, this is unusual because wild Pokémon have their PP deducted normally when they use any other moves in battle. For comparison: In [Generation I](https://bulbapedia.bulbagarden.net/wiki/Generation_I "Generation I"), all wild Pokémon were caught with full PP for all moves. From Generation III onwards, if a wild Pokémon uses Transform, then Transform's PP is deducted normally.

### Transform held item glitch

In Japanese versions of Diamond and Pearl, if a Pokémon [holding an item](https://bulbapedia.bulbagarden.net/wiki/Held_item "Held item") uses Transform and has its item stolen, as long as it does not faint before the end of the battle, both the transforming Pokémon and the thief will retain the item after the battle.

### Transform faint glitch

In the Japanese version of [Pokémon Diamond and Pearl](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Diamond_and_Pearl_Versions "Pokémon Diamond and Pearl Versions"), if a transformed Pokémon faints, it will keep the moves it learned via Transform. This glitch may be potentially used to teach any move (except [Struggle](https://bulbapedia.bulbagarden.net/wiki/Struggle_\(move\) "Struggle (move)")) to the transformed Pokémon. Any of the previous moves are deleted, including Transform.

Alternatively, [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)") may also be called by [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)"), [Copycat](https://bulbapedia.bulbagarden.net/wiki/Copycat_\(move\) "Copycat (move)"), [Assist](https://bulbapedia.bulbagarden.net/wiki/Assist_\(move\) "Assist (move)"), or [Metronome](https://bulbapedia.bulbagarden.net/wiki/Metronome_\(move\) "Metronome (move)"). For instance, a [Gengar](https://bulbapedia.bulbagarden.net/wiki/Gengar_\(Pok%C3%A9mon\) "Gengar (Pokémon)") with [Mimic](https://bulbapedia.bulbagarden.net/wiki/Mimic_\(move\) "Mimic (move)") can temporarily copy [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)") in battle, and then transform itself into a Pokémon with the desired moveset in order to perform this glitch. If Gengar faints while transformed, it will keep the moveset copied with Transform.

Exploiting this glitch allows for [Ditto](https://bulbapedia.bulbagarden.net/wiki/Ditto_\(Pok%C3%A9mon\) "Ditto (Pokémon)") to learn moves other than [Transform](https://bulbapedia.bulbagarden.net/wiki/Transform_\(move\) "Transform (move)"), and to subsequently pass down any [Egg Move](https://bulbapedia.bulbagarden.net/wiki/Egg_Move "Egg Move") in the [Day Care](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Day_Care "Pokémon Day Care") if the paired Pokémon is female.

This glitch also allows Ditto to enter [Super Contests](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Super_Contest "Pokémon Super Contest") and earn their respective [Ribbons](https://bulbapedia.bulbagarden.net/wiki/Ribbon "Ribbon"). Usually, Ditto would be unable to enter any Super Contest, because only Pokémon with at least two moves may enter.

### Smeargle cloning glitch

*Main article: [Cloning glitches#Smeargle cloning glitch](https://bulbapedia.bulbagarden.net/wiki/Cloning_glitches#Smeargle_cloning_glitch "Cloning glitches")*

If the player lures a [Smeargle](https://bulbapedia.bulbagarden.net/wiki/Smeargle_\(Pok%C3%A9mon\) "Smeargle (Pokémon)") very close to a tree in the [Terarium](https://bulbapedia.bulbagarden.net/wiki/Terarium "Terarium") in [Pokémon Scarlet and Violet](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Scarlet_and_Violet "Pokémon Scarlet and Violet"), has the wild Smeargle use [Sketch](https://bulbapedia.bulbagarden.net/wiki/Sketch_\(move\) "Sketch (move)") to copy Transform, then has the wild Smeargle use it, if the player then runs away from the battle, the Smeargle will become a clone of the Pokémon it transformed into, and the player can then re-encounter the clone in a battle to capture it. The clone will disappear from the overworld if the game is saved and restarted if it is not caught.

This glitch is no longer possible because Transform cannot be used by wild Smeargle as of version 3.0.1.
